# Política de Privacidade — Adeus, Pobreza!

Última atualização: 11 de junho de 2026

O jogo **"Adeus, Pobreza!"** ("nós", "o app") é desenvolvido por Thalis
Gaeta. Esta política descreve como tratamos suas informações.

## Dados que coletamos

O app em si **não coleta, armazena ou transmite dados pessoais**. Todo o
progresso do jogo (moedas, doações, conquistas) é salvo apenas no seu
aparelho e nunca sai dele.

## Serviços de terceiros

O app usa os seguintes serviços do Google, que podem coletar
identificadores do dispositivo conforme suas próprias políticas:

- **Google AdMob** (exibição de anúncios): pode coletar o ID de
  publicidade do dispositivo para veicular e medir anúncios.
  Política: <https://policies.google.com/privacy>
- **Google Play Billing** (compras no app): processa os pagamentos.
  Nós não temos acesso aos seus dados de pagamento.

## Compras no app

As "doações" dentro do jogo são compras digitais de entretenimento,
processadas pelo Google Play. Elas desbloqueiam conteúdo no jogo e não
são repassadas a terceiros nem a instituições de caridade.

## Crianças

O app não coleta dados de nenhum usuário, incluindo crianças. Os
anúncios são configurados para classificação livre.

## Exclusão de dados

Para apagar todos os dados do jogo, use o botão de reset dentro do app
ou desinstale o aplicativo.
